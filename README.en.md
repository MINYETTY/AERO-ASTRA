# Misión Orión

[English](README.md) ·

A 2D pixel-art game for 1 to 4 players (the game itself is in Spanish). The crew travels from Earth to the Moon aboard the Orion spacecraft, then builds and runs a lunar base until it becomes self-sufficient.

It is inspired by Among Us (a crew with roles completing missions) and Fallout Shelter (a lunar base seen in cross-section). The scientific facts come from NASA and ESA, with their sources cited.

![Lunar base](assets/base_lunar_1920x1080.png)

## How to play

Download or clone the repository and open `index.html` in your browser. Nothing to install.

| Action | Keyboard | Touchscreen |
| --- | --- | --- |
| Move | Arrow keys or WASD | On-screen buttons |
| Use / interact | E, Space or Enter | USAR (Use) button |
| Close windows | Esc | Salir / Cerrar (Exit / Close) button |

## The two acts

**Act 1 · The Orion spacecraft.** Go through the 7 phases of the journey: preparation and launch, ascent, translunar injection, transit, lunar orbit, descent, and base assembly. Each phase has missions solved through one of 21 minigames (GO/NO-GO poll, engine burns, docking, landing, spacewalk and more). The mission clock and telemetry follow a simplified model of the real Artemis trajectory.

**Act 2 · The lunar base.** Build rooms (power plant, greenhouse, lab, infirmary, radiation shelter and others), assign crew members, do research, send rover expeditions, and survive incidents and solar storms. You win when the base is self-sufficient for a full lunar day.

You can also start directly at the lunar base from the start menu.

## Roles

| Role | On the spacecraft | At the base |
| --- | --- | --- |
| Commander | Ignition, orbits and decisions | Sets priorities and the clock speed |
| Pilot | Maneuvers, docking and landing | Drives the rovers and expeditions |
| Specialist | Life support, communications and science | Researches and leads science expeditions |
| Engineer | Power, water, structure and computers | Builds, upgrades and repairs the base |

## Other features

- **Dr. Marina Solís (advisor):** answers questions about the Moon, Mars, the Sun, rockets, astronauts and space history, with verified facts and their sources.
- **Logbook:** a record of what happens during the mission.
- **Saving:** automatic in the browser. You can also export and import a save code.
- **Sound:** generated with Web Audio, no audio files.

## Features that only work inside Claude

The game was made as a Claude artifact. Outside Claude (for example, opening `index.html` on your computer or on GitHub Pages), single-player mode, browser saving and save codes all work. These three features need the Claude platform and turn themselves off outside it:

- Online multiplayer (up to 4 players)
- The advisor's online mode (answers generated by Claude)
- Per-user cloud saving

## Project structure

```
├── index.html      The whole game: HTML, CSS and JavaScript in one file
├── assets/         Project images
├── README.md       Spanish README
└── README.en.md    English README
```

Inside `index.html`, the code is split into modules marked with comments:

| Module | What it contains |
| --- | --- |
| `datos_nave.js` | Roles, phases and missions for Act 1 |
| `dialogos.js` | Dialogue for the four crew members |
| `conocimiento.js` | The advisor's knowledge base |
| `datos_base.js` | Rooms, incidents, research and expeditions for Act 2 |
| `motor.js` | Utilities, sound and pixel art drawn in code |
| `trayecto.js` | Earth → Moon trajectory model |
| `cinematicas.js` | Short cutscenes between phases |
| `minijuegos.js` | The 21 minigames |
| `nave.js` | Act 1 logic and drawing |
| `ui.js` | Shared interface: HUD, missions, logbook |
| `asesora.js` | Dr. Solís, the advisor |
| `base_lunar.js` | Act 2 simulation |
| `ui_base.js` | Lunar base drawing and panels |
| `red.js` | Multiplayer |
| `principal.js` | Screens, saving and main loop |

## Technology

Plain HTML5, CSS and JavaScript, no libraries. All graphics are drawn in code on `<canvas>`. The fonts (Press Start 2P and VT323) load from Google Fonts.

## Credits

Scientific data: NASA, ESA and the NASA Technical Reports Server (NTRS); sources are cited inside the game. The base's production and consumption figures are made up for gameplay.
